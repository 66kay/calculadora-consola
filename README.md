# Calculadora de consola

Calculadora en Python que se usa desde la terminal. Es mi primer proyecto del portafolio.

## Funciones
- Suma, resta, multiplicación y división
- Avisa si intentas dividir por cero
- Permite hacer varias operaciones seguidas

## Cómo ejecutar
Necesitas Python 3.

```bash
python calculadora.py
```

## Lo que aprendí
- Pedir datos con `input()` y convertirlos a número con `float()`
- Usar condicionales `if / elif / else`
- Repetir con un bucle `while`
